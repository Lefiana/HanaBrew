# Troubleshooting

| Symptom                                                                | Likely cause / fix                                                                                                                                                                               |
| ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| API exits with `Invalid environment configuration`                     | A variable in `.env` is missing or malformed; the message lists each one                                                                                                                         |
| `P1001: Can't reach database server` / `/api/health/ready` returns 503 | PostgreSQL is not running (`docker compose up -d postgres`) or `DATABASE_URL` points at the wrong host/port/password                                                                             |
| `ERR_PNPM_IGNORED_BUILDS` on install                                   | A new dependency has an install script. Review it, then allow or deny it under `allowBuilds` in `pnpm-workspace.yaml`                                                                            |
| Signed in but redirected back to `/sign-in`                            | Cookie not sent: web and API must share a site (`localhost` ↔ `localhost`), `CORS_ALLOWED_ORIGINS` must contain the exact web origin, and `NEXT_PUBLIC_API_URL` must be the URL the browser uses |
| `e2e` refuses to run                                                   | `TEST_DATABASE_URL` is missing, or its database name does not end in `_test` (the suite drops the schema)                                                                                        |
| Prisma reports drift on `pnpm db:migrate`                              | See "Verification status" item 2 in the README (migrations were hand-written)                                                                                                                    |
| Theme flashes on load                                                  | Ensure the inline `THEME_SCRIPT` in `app/layout.tsx` is intact                                                                                                                                   |
